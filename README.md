# car-accident-survival-logit
Logistic regression for car crash survivability factors with model comparison and diagnostics


## Data

Source: Road Accident Survival dataset (Kaggle).

This repository does not include the raw dataset file.
To run the analysis, download the dataset from Kaggle and load it into R as `crash.data`.

Expected columns:
- Survived (0/1)
- Age
- Gender
- Speed_of_Impact
- Helmet_Used (Yes/No)
- Seatbelt_Used (Yes/No)
